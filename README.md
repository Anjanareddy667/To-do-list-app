📝 To-Do List in Python

A simple command-line based To-Do List application written in Python.
This project lets users add tasks, view tasks, and remove tasks easily through a menu-driven interface.

🚀 Features
✔ Add new tasks
👀 View all tasks
❌ Remove tasks by selecting task number
🔁 Menu repeats until user selects Exit
💡 Beginner-friendly Python project

  🧠 How It Works

The program stores tasks in a Python list.
Every time the user inputs a choice, it runs the corresponding function:
1 → Add Task
2 → View All Tasks
3 → Remove Task
4 → Exit Program
